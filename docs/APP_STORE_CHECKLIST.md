# App Store / TestFlight Checklist

- Replace placeholder bundle identifier.
- Configure signing team.
- Replace development API-key injection with mobile-safe authentication.
- Provide production-safe API base URL.
- Add final app icon assets.
- Add privacy manifest if required by integrated SDKs.
- Validate camera permission copy.
- Test scanner on a physical iPhone.
- Test Dynamic Type, VoiceOver, Dark Mode, and Reduce Motion.
- Confirm no API keys are committed or printed.
- Run real-data smoke tests for complete and incomplete products.
